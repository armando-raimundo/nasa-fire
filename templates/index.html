Arquitetura do Sistema

Como os dados orbitais chegam até este painel:

  • 1. Captação Orbital: Os sensores infravermelhos VIIRS (375 m) e MODIS (1 km) varrem a superfície terrestre e identificam anomalias térmicas.
  • 2. Processamento FIRMS: A API da NASA disponibiliza coordenadas, temperatura de brilho (bright_ti4 / brightness) em Kelvin e a potência radiativa (FRP).
  • 3. Análise & Visualização: O servidor Python une as fontes, converte para °C, filtra por confiança, funde deteções duplicadas num raio de ~0,6 km e calcula uma intensidade comparável entre sensores.
Fonte oficial: firms.modaps.eosdis.nasa.gov
